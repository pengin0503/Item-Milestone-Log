## 記入ルール

- 状態は `未検証` / `検証中` / `コンパイルOK` / `サーバーOK` / `手動確認OK` のいずれかで記入する
- 検証を1つ進めるごとに状態を更新し、差分・メモにコンパイルエラーや API 差分の要点を残す
- NeoForge の min/latest は実在するバージョンを公式プロジェクトページで確認してから記入する（推測で書かない）
- 分割判断は DESIGN §4.3 の基準に従い、判断したらその根拠を該当行に記録する
